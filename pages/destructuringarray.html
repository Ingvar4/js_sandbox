Деструктуризация массивов в JavaScript

назад

Пример с присваиванием значений переменным из массивов

  
    const numbers = [1, 3, 5, 7, 9, 11];
    const fruits = ['banana', 'cherry', 'lemon', 'orange', 'pear'];

    const [firstNum, secondNum, thirdNum, fourthNum ] = numbers;
    const [first, second, third, fourth] = fruits;

    console.log(firstNum, secondNum, thirdNum, fourthNum); //1 3 5 7
    console.log(first, second, third, fourth); //banana cherry lemon orange

Пример, если нужно пропустить какие-либо элементы

  
    const fruits = ['banana', 'cherry', 'lemon', 'orange', 'pear'];

    const [first, , third, , fifth] = fruits;
    console.log(first, third, fifth); //banana lemon pear

Оставшиеся неиспользованные индексы можно определить в rest

  
    const fruits = ['banana', 'cherry', 'lemon', 'orange', 'pear'];

    const [first, second, ...tail] = fruits;
    console.log(first, second, tail); //banana cherry [ 'lemon', 'orange', 'pear' ]

Пример того, что при деструктурирующем присваивании можно задавать значения по умолчанию

Значение по умолчанию присвоится, если в изначальном массиве этого значения нет

  
    const fruits = ['banana', , 'lemon', 'orange', 'pear'];

    const [first, second = 'grape', ...tail] = fruits;
    console.log(first, second, tail); //banana grape [ 'lemon', 'orange', 'pear' ]

Пример с оператором ИЛИ || для тех случаев, когда массив по какой то причине недоступен (к примеру нет ответа от сервера)

  
    const fruits = null;

    const [first, second = 'grape', ...tail] = fruits || [];
    console.log(first, second, tail); //undefined grape []

Пример с многомерным массивом

Вложенные массивы в многомерном массиве становятся отдельными переменными

  
    const fruits = ['banana', ['cherry', 'lemon'], 'orange', 'pear'];

    const [first, second, third, fourth] = fruits;
    console.log(first, second, third, fourth); //banana [ 'cherry', 'lemon' ] orange pear

    //получилось что переменная second это весь вложенный массив

Если нам нужно добиться соответствия с оригинальным массивом, деструктурирование нужно сделать так же вложенным

  
    const fruits = ['banana', ['cherry', 'lemon'], 'orange', 'pear'];

    const [first, [second, third], fourth] = fruits;
    console.log(first, second, third, fourth); //banana cherry lemon orange

Если нужно избежать ошибок при отсутствии вложенного массива, ему присваивается значение по умолчанию пустого массива

  
    const fruits = null;

    const [first, [second, third] = [], fourth] = fruits || [];
    console.log(first, second, third, fourth); //undefined undefined undefined undefined

Пример с созданием "заглушек" для отсутствующих переменных

  
    const fruits = null;

    const [first = 'какой-то фрукт', [second = 'какой-то фрукт', third = 'какой-то фрукт'] = [], fourth = 'какой-то фрукт'] = fruits || [];
    console.log(first, second, third, fourth); //какой-то фрукт какой-то фрукт какой-то фрукт какой-то фрукт

Пример как быстро заменить значения переменных. 

  
    let a  = 5;
    let b = 10;

    [a, b] = [b, a];
    console.log(a, b); //10 5

В правой части создаётся массив, а в левой - деструктуризация. Слева объявляются новые переменные, а справа им пресваиваются значения данными из массива
