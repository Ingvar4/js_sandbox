Замыкание (Closer)

назад

Замыкание - это функция, которая запоминает значение переменных из окружающей её области видимости даже после того, как эта область видимости завершила свою работу.

Функция, создающая свою область видимости для блока кода, который выдаётся как рельтат работы этой функции

  
    let multiplier;
    multiplier = 2;

    let result = function (number) {
      return number * multiplier;
    };

    console.log(result(5)); //10
    multiplier = 3;
    console.log(result(5)); //15
  

  
    function createMultiplier(multiplier) {
      return function (number) {
        return number * multiplier;
      };
    };

    const double = createMultiplier(2);
    const triple = createMultiplier(3);

    console.log(double(5)); //10
    console.log(triple(5)); //15
