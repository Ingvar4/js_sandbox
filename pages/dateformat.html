Форматирование даты и времени

назад

toLocaleDateString()

  
    const currentDate = new Date();
    const myFormattedDate = currentDate.toLocaleDateString('ru-RU', {
      weekday: 'long',
    });

    console.log(myFormattedDate); //четверг

Использование параметра options

   
    const currentDate = new Date();

    const options = {
      weekday: "long",
      year: "numeric",
      month: "long",
      day: "numeric",
    };

    const myFormattedDate = currentDate.toLocaleDateString('ru-RU', options);

    console.log(myFormattedDate); //четверг, 12 марта 2026 г.

toLocaleTimeString()

   
    const currentDate = new Date();
    const myFormattedTime = currentDate.toLocaleTimeString('ru-RU');

    console.log(myFormattedTime); //11:54:22
