Метод map()

назад

Синтаксис

  
    const newArray = array.map(callback(element[, index[, array]])[, thisArg]);
  • callback - функция, которая будет вызвана для каждого элемента массива. Она должна возвращать значение, которое будет добавлено в новый массив.
  • element - текущий обрабатываемый элемент массива
  • index (необязательно) - индекс текущего обрабатываемого элемента в массиве
  • array (необязательно) - исходный массив, на котором был вызван метод map
  • thisArg (необязательно) - значение, используемое в качесте this при выполнении функции callback

Пример

  
    const numbers = [1, 2, 3, 4, 5];
    const doubledNumbers = numbers.map((num) => num * 2);
    console.log(doubledNumbers); //[ 2, 4, 6, 8, 10 ]

Пример преобразования массива строк в новый массив с длинной этих строк

  
    const words = ['Apple', 'Banana', 'Cherry', 'date'];
    const wordLengths = words.map((word) => word.length);
    console.log(wordLengths); //[ 5, 6, 6, 4 ]

Пример с коллекцией объектов

  
    const people = [
      {name: 'Alice', age: 25},
      {name: 'Bob', age: 35},
      {name: 'John', age: 20},
    ];

    const names = people.map(person => person.name);
    console.log(names); //[ 'Alice', 'Bob', 'John' ]

    const names2 = people.map(person => person.name).join(', ');
    console.log(names2); //Alice, Bob, John

Пример с рендером через map в html

  
    const tasks = [
      { id: 1, description: 'Купить хлеба', completed: false },
      { id: 2, description: 'Сделать домашку', completed: true },
      { id: 3, description: 'Позвонить маме', completed: false },
    ];

    const tasklist = document.getElementById('task-list');
    const taskItems = tasks.map((task) => 
      `<li>${task.description}</li>`).join('');

    tasklist.innerHTML = taskItems;
