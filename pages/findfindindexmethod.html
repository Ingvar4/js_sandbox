Методы find() и findIndex()

назад

Синтаксис

  
    arr.find(callback[, thisArg])
  • callback - функция, вызывающаяся для каждого значения в массиве, поигимает 3 аргумента
  • element - текущий обрабатываемый элемент в массиве
  • index - (необязательный параметр) индекс текущего обрабатываемого элемента в массиве
  • array - (необязательный параметр) массив, по которому осуществляется проход
  • thisArg - (необязательный параметр) значение, используемое в качестве this при выполнении callback

Возвращаемое значение - значение элемента из массива, если элемент прошел проверку, иначе undefined

  
    const users = [
      {

    const userInMinsk = users.find((user) => user.city === 'Минск');
