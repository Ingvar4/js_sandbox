Встроенные методы массивов

назад

Array.isArray()

Проверка, является ли переменная массивом

  
    const array = [1, 2, 3];
    const notArray = 'not an array';

    console.log(Array.isArray(array)); //true
    console.log(Array.isArray(notArray)); //false

concat()

Объединяет 2 и > массива или строки. Возвращает новый массив. Не мутирует исходный массив.

  
    const array1 = [1, 2, 3];
    const array2 = [3, 3, 4];
    const newArray = array1.concat(array2);
    console.log(newArray); //[1, 2, 3, 3, 3, 4]

Пример с 3мя массивами

  
    const array1 = [1, 2, 3];
    const array2 = [3, 3, 4];
    const array3 = [7, 8, 9];
    const newArray = array1.concat(array2, array3);
    console.log(newArray); //[1, 2, 3, 3, 3, 4, 7, 8, 9]

indexOf()

Поиск индекса первого вхождения указанного элемента в массиве.

Возвращает индекс элемента или -1

Принимает 2 аргумента:

  • искомый элемент
  • начальный индекс(опционально). По умолчанию 0
  
    const array1 = [1, 2, 3, 4, 3, 5];
    const index = array1.indexOf(3);
    console.log(index); //2

    //первая 3ка, встречающаяся в массиве имеет индекс 2

Пример с 2мя аргументами

  
    const array1 = [1, 2, 3, 4, 3, 5];
    const index = array1.indexOf(3, 3);
    console.log(index); //4

    //поиск начинается с 3го элемента массива

lastIndexOf()

Поиск индекса последнего вхождения указанного элемента в массиве

Возвращает индекс элемента или -1

Принимает 2 аргумента:

  • искомый элемент
  • начальный индекс в обратном направлении(опционально). По умолчанию раверн length -1
  
    const array1 = [1, 2, 3, 4, 3, 5];
    const index = array1.lastIndexOf(3);
    console.log(index); //4

    //Метод ищет первую 3ку с конца, она под индексом 4

Пример с 2мя аргументами

  
    const array1 = [1, 2, 3, 4, 3, 5];
    const index = array1.lastIndexOf(3, 3);
    console.log(index); //2

    //Находит последнюю 3ку с конца под индексом 2

pop()

Удаляет последний элемент из массива и возвращает этот удалённый элемент.

Мутирует исходный массив

  
    const array1 = [1, 2, 3, 4, 3, 5];
    const lastElement = array1.pop();
    console.log(lastElement); //5
    console.log(array1); //[1, 2, 3, 4, 3]

удаление всех элементов из массива

  
    const array = [10, 20, 30, 40, 30, 50];
    while (array.length > 0) {
      console.log(array.pop());
    };

    console.log(array);
    //50
    //30
    //40
    //30
    //20
    //10
    //[]

push()

Добавляет элементы в конец массива и возвращает новую длинну массива.

Мутирует исходный массив

  
    const array = [1, 2, 3];
    const newLength = array.push(4);
    console.log(newLength); //4
    console.log(array); //[1, 2, 3, 4]

пример с добавлением элементов в массив через цикл

  
    const array = [];
    for (let i = 1; i <= 5; i++) {
      array.push(i);
    }
    console.log(array); //[1, 2, 3, 4, 5]

shift()

Удаляет первый элемент из массива и возвращает этот удалённый элемент.

Мутирует исходный массив

  
    const array = [1, 2, 3, 4];
    const firstElement = array.shift();
    console.log(firstElement); // 1
    console.log(array); //[2, 3, 4]

unshift()

Добавление 1 или нескольких элементов в начало массива

Возвращает новую длинну массива. Мутирует исходный массив

  
    const array = [2, 3, 4];
    const newLength = array.unshift(1);
    console.log(newLength); //4
    console.log(array); //[1, 2, 3, 4]

includes()

Определяет, содержит ли массив определённый элемент

Возвращает true или false

Не изменяет исходный массив

Пример с поиском начиная с 2го индекса

  
    const array = [1, 2, 3, 4, 5, 6];
    const hasElement = array.includes(3, 2);
    console.log(hasElement); //true

    //ищет есть ли 3 начиная с 2 индекса

slice()

Создаёт новый массив, содержащий копию части исходно массива. Возвращает новый массив, содержащий выбранный элементы. Не изменяет исходный массив. Принимает 2 аргумента:

  • начальный индекс (включительно), с которого начинается выбор элементов
  • конечный индекс (не включительно), до которого выбираются элементы
  
    const array = [1, 2, 3, 4, 5, 6];
    const newArray = array.slice(1, 4);
    console.log(newArray); //[2, 3, 4]
    console.log(array); //[1, 2, 3, 4, 5, 6]

отрицательные индекса отсчитываются от конца массива

  
    const array = [1, 2, 3, 4, 5, 6];
    const newArray = array.slice(-3, -1);
    console.log(newArray); //[4, 5]
    console.log(array); //[1, 2, 3, 4, 5, 6]

splice()

Используется для удаления, заменты или добавления элементов. Возвращает массив, удалённых элементов. Мутирует исходный массив. Принимает 3 аргумента:

  • начальный индекс (включительно), с которого начинается изменение массива.
  • количество удаляемых элементов, начиная с начального индекса. По умолчанию равен 0
  • элементы для добавления (опционально), начиная с начального индекса
  
    const array = [1, 2, 3, 4, 5, 6];
    const removedElements = array.splice(2, 2);
    console.log(removedElements); //[3, 4]
    console.log(array); //[1, 2, 5, 6]
  

  
    const array = [1, 2, 3, 4, 5, 6];
    const removedElements = array.splice(0, 2);
    console.log(removedElements); //[1, 2]
    console.log(array); //[3, 4, 5, 6]
  

  
    const array = [1, 2, 3, 4, 5];
    const removedElements = array.splice(2, 0, 6, 7); //количество удаляемых элементов - 0
    console.log(removedElements); //[]
    console.log(array); //[1, 2, 6, 7, 3, 4, 5]
  

  
    const array = [1, 2, 3, 4, 5];
    const removedElements = array.splice(2, 2, 6, 7);
    console.log(removedElements); //[3, 4]
    console.log(array); //[1, 2, 6, 7, 5]

    // 2 - начало со 2го индекса
    // 2 - количество удалённых элементов
    // 6 - добавление 6
    // 7 - добавление 7

удаление после определённого индекса

  
    const array = [1, 2, 3, 4, 5];
    const removedElements = array.splice(2);
    console.log(removedElements); //[3, 4, 5]
    console.log(array); //[1, 2]

join()

Объединяет все элементы массива в строку с указанным разделителем (по умолчанию запятая)

Не изменяет исходный масив

  
    const array = ['apple', 'banana', 'cherry'];
    const result = array.join();
    console.log(result); //apple,banana,cherry
    console.log(array); //['apple', 'banana', 'cherry']
  

  
    const array = ['apple', 'banana', 'cherry'];
    const result = array.join(' - ');
    console.log(result); //apple - banana - cherry
    console.log(array); //['apple', 'banana', 'cherry']

reverse()

Изменяет порядок элементов в массиве на обратный

Мутирует исходный массив

  
    const array = ['apple', 'banana', 'cherry'];
    array.reverse();
    console.log(array); //['cherry', 'banana', 'apple']

Если нужно сохранить исходный массив не мутированным

вставка slice() позволяет избежать мутации

  
    const originalArray = [1, 2, 3, 4, 5];
    const reversedArray = originalArray.slice().reverse();
    console.log(reversedArray); //[5, 4, 3, 2, 1]
    console.log(originalArray); //[1, 2, 3, 4, 5]
