Рекурсия

назад

Рекурсия это метод решения задач, при котором функция вызывает саму себя для решения подзадач.

Базовый случай (base case) (терминальное условие) - это условие, при котором функция перестаёт вызывать саму себя и возвращает результат. Без базового случая рекурсия может привести к бесконечному циклу и переполнению стека вызовов.

Рекурсивный случай (Recursive Case) (правило движения по рекурсии) - это условие, при котором функция вызывает саму себя с изменёнными аргументами, чтобы приблизиться к базовому случаю.

  
    let myArray = [2, 4, 6, 8, 10];

    function getLength(arr) {
      if(arr.pop() === undefined) {
        return 0;
      }

      return 1 + getLength(arr);
    }

    let length = getLength(myArray);
    console.log('Длинна массива: ' + length); //Длинна массива: 5
