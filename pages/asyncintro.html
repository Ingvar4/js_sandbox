Знакомство с асинхронностью

назад 
  
    console.log('Привет, я иду первым!');
    setTimeout(() => console.log('Теперь иду я?'), 2000);
    setTimeout(() => console.log('Когда моя очередь?'), 0);
    console.log('Разве я последний?');

    // Привет, я иду первым!
    // Разве я последний?
    // Когда моя очередь?
    // Теперь иду я?

console.log - синхронная функция, выполняется сразу. Она попадает в call stack, затем в консоль. Соответственно оба console.log выводятся один за другим в порядке очереди.

setTimeout - асинхронная функция, она отправляется в web apis после call stack. В web apis асинхронная функция находится пока не выполнятся все синхронные.

Когда call stack очищается, асинхронные функции перемещаются в callback queue, затем в call stack по очерёдности, в зависимости от своих таймеров.
