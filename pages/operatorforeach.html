Перебор элементов массива. Метод forEach

назад 
  
    const arrNums = [3, 5, 7, 77, 55];

    arrNums.forEach((el) => {
      console.log(el);
    });

Пример работы с индексом массива

  
    const arrNums = [3, 5, 7, 77, 55];

    arrNums.forEach((el, index) => {
      console.log(`${el}: ${index}`);
    });

Пример с дополнительным выводом самого массива

  
    const arrNums = [3, 5, 7, 77, 55];

    arrNums.forEach((el, index, arr) => {
      console.log(`${el}: ${index}, массив ${arr}`);
    });
