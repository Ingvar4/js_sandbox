Метод reduce()

назад

Метод reduce() перебирает элементы массива и сводит их к одному значению.

  
    const array = [1, 2, 3, 4];

    const initialValue = 10;
    const sumWithInitial = array.reduce(
      (accumularor, currentValue, index, array) => {
        return accumularor + currentValue;
      },
      initialValue
    );

    console.log(sumWithInitial);

Пример с подсчётом средней зарплаты сотрудников

  
    const employees = [
      { id: 1, name: 'Alice', salary: 50000 },
      { id: 2, name: 'Bob', salary: 60000 },
      { id: 3, name: 'Gop', salary: 55000 },
      { id: 4, name: 'Pop', salary: 70000 },
      { id: 5, name: 'Poop', salary: 45000 },
    ];

    const totalSalary = employees.reduce(
      (sum, employees) => sum + employees.salary, 0
    );

    let avarageSalary = totalSalary / employees.length;
    console.log(avarageSalary); //56000
