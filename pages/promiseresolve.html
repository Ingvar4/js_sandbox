Promise.resolve() / Promise.reject()

назад

Пример с двумя аналогичными записями

  
    function fn() {
      return new Promise((resolve) => {
        resolve(1);
      });
    };

    function fn2() {
      return Promise.resolve(1);
    };

Promise.reject() - возвращает объект promise который отклонён по какой-либо причине

  
    const data = await Promise.reject(new Error('Данные не получены. Статус 500'));
